# Evaluation reports

This directory holds evaluation outputs generated by `ml/train_url_model.py`.

Files are **generated**, not committed to version control by default.

## Expected files after training

| File | Description |
|------|-------------|
| `url_model_evaluation.json` | Precision, recall, F1-score, confusion matrix, class balance |

Metrics are derived from a held-out test set only.
They are never fabricated or copied from external sources.
