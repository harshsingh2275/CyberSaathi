# Evaluation reports

This directory holds evaluation outputs generated by `ml/train_url_model.py`.

Files are **generated**, not committed to version control by default.

To reproduce, run from the repository root:

```bash
python ml/train_url_model.py
```

## Files after training

| File | Description |
|------|-------------|
| `evaluation_report.json` | Precision, recall, F1-score, confusion matrix, FPR, FNR, class balance |
