# Trained model artifacts

This directory holds artifacts generated by `ml/train_url_model.py`.

Files written here are **generated**, not committed to version control by default
(covered by the root `.gitignore`).

To reproduce these artifacts, run:

```bash
python ml/train_url_model.py
```

## Expected files after training

| File | Description |
|------|-------------|
| `url_model.joblib` | Trained scikit-learn pipeline (vectoriser + classifier) |
| `feature_schema.json` | Feature names and version; must match inference code |
| `training_report.json` | Recorded random seed and dataset metadata |

## Runtime path

The backend loads artifacts from this directory by default.
The path is configurable via the `MODEL_PATH` environment variable.
See `backend/.env.example` for details.
