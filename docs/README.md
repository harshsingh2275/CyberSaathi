# CyberSaathi AI — Antigravity Build Pack

This folder contains the execution instructions for building CyberSaathi AI in four days.

## Files
- `task.md` — sequential tasks and acceptance criteria.
- `agents.md` — persistent instructions for Antigravity.
- `prompts.md` — copy-ready prompts and commit statements for each task.
- `manual_actions.md` — user-side/manual actions and safety checks.
- `prd.md` — product requirements.
- `architecture.md` — system architecture, APIs, and workflows.
- `deployment_guide.md` — deployment procedure and verification checklist.
- `start_to_finish_guide.md` — short execution order.
- `project.md` — Hinglish explanation of the project.
- `model_guide.md` — tasks that should use Claude in Antigravity.
- `operations-guide.md` — post-build maintenance.
- `design.md` — to be added separately by the user.

## How to use
1. Copy these files into the root of the project repository.
2. Open the repository in Antigravity.
3. Read `agents.md` and run `P-00` from `prompts.md`.
4. Follow the sequence in `start_to_finish_guide.md` and `task.md`.
5. Use Claude for the critical tasks listed in `model_guide.md`.
6. Perform only the relevant manual steps from `manual_actions.md`.
7. Do not claim implementation, metrics, tests, or deployment without evidence.

**Important:** These are build instructions, not proof that the application has already been implemented.
